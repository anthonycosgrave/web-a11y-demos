# Web a11y demos

The purpose of this repository is a place to host exploring programming related web accessibility concepts using 
different frontend frameworks or web tech to implement them and testing with assistive technologies (predominantly
screen readers).

## Error Summary for form validation (React JavaScript) - "accessible-form-validation-react"
Using guidance from eBay, GOVUK and WebAIM to provide an accessible error feedback mechanism for web forms.

## Using `aria-activedescendant` to create a editable combobox (vanilla js) - "aria-activedescendant-editable-list-combobox-with-autocomplete"
Based on the APG pattern demonstrates "visual focus" on list options so that a screen reader can announce the actual option selected.

## Using the "roving tabindex" technique (vanilla js) - "roving-tabindex-toolbar"
Another navigation technique from the APG with the classic toolbar example. 

## Accessible pagination (React TypeScript) - "pagination"
Using DummyJSON.com product API to implementing pagination based on guidance from GOVUK, GitHub Primer and eBay. I also take a quick look at how
"Big Search" (Google, Bing and Duckduckgo) handles their pagination.
